# Getting Started

Welcome to TW Components - a collection of custom HTML components designed for Bulwark Exterminating LLC projects. This library provides enhanced user interface elements that behave like native HTML components while offering additional functionality and styling.

## What is TW Components?

TW Components is a library of custom HTML components that enhance the standard HTML input elements with additional functionality:

- **Native HTML Behavior**: Components behave like standard HTML elements for familiarity
- **Enhanced Functionality**: Additional features like auto-resizing textareas, PIN inputs, and signature capture
- **Easy Integration**: Simple to include in existing HTML projects with minimal setup
- **Form-First Design**: Built with form handling and validation in mind

## Key Features

### Enhanced Input Components

- **Auto-Resize Textarea**: Automatically adjusts height based on content
- **List Input**: Manage arrays of values with an intuitive interface
- **PIN Input**: Secure PIN entry with customizable digit length
- **Passkey Input**: WebAuthn passkey authentication support
- **Select Input**: Enhanced select dropdowns with better UX
- **Signature Input**: Canvas-based signature capture

### View Components

- **Calendar**: Interactive calendar component with date selection
- **Filter**: Real-time filtering interface for lists and data

## Browser Support

TW Components works in all modern browsers:

- Chrome 88+
- Firefox 78+
- Safari 14+
- Edge 88+
